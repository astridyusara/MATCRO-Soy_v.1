# MATCRO-Soy v.1

**MATCRO-Soy v.1** is a process-based eco-physiological model for simulating soybean yield.

This program is developed by Yuji Masutomi (National Institute of Environmental Studies, Japan) masutomi.yuji[at]nies.go.jp 
and some parameterization changes by Astrid Yusara (Graduate School of Agriculture, Hokkaido University, Japan)
